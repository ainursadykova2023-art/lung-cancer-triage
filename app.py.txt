# 🫁 Lung Cancer Triage & Differential Diagnosis Model

## О проекте
Данный проект представляет собой систему машинного обучения для дифференциальной диагностики и первичного триажа пациентов с подозрением на рак легких. Модель анализирует клинические симптомы и анамнез для оценки вероятности злокачественного процесса, помогая приоритизировать пациентов для направления на КТ.

## Данные
Использован медицинский датасет, включающий 276 записей. Данные отражают реальную клиническую картину специализированного учреждения с естественным дисбалансом классов:
* **Класс 1 (Подтвержденный диагноз):** 238 пациентов (86%)
* **Класс 0 (Иные патологии/Без рака):** 38 пациентов (14%)

## Стек технологий
* **Анализ данных:** Pandas, NumPy
* **Визуализация (EDA):** Matplotlib, Seaborn
* **Машинное обучение:** Scikit-learn (Logistic Regression, Random Forest)
* **API:** FastAPI

## Результаты моделирования
В ходе работы были обучены и протестированы две модели с использованием параметра `class_weight='balanced'` для компенсации дисбаланса:

1. **Baseline Model (Logistic Regression):** 
   * ROC-AUC: **0.9583**
2. **Improved Model (Random Forest):** 
   * ROC-AUC: **0.9557**

Baseline-модель (Логистическая регрессия) показала отличную способность к обобщению на медицинских данных, достигнув полноты (Recall) **0.96** для группы высокого риска.
